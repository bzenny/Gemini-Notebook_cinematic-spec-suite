# Security Policy

## Reporting Vulnerabilities or Malformed Specifications

While this repository consists solely of structured text prompts and `.yaml` specifications, prompt injection, unsafe text execution, or CI pipeline vulnerabilities are taken seriously.

### How to Report an Issue
If you discover a security issue or malformed instruction set that causes deterministic crashes in LLM visual parsing:
1. **Do NOT** open a public issue.
2. Email the repository maintainers directly or use GitHub Private Vulnerability Reporting via the **Security** tab.
3. Include the specific `.yaml` file name, input prompt, and target model version (e.g., Gemini 1.5 Pro).
